# LibreOffice Clean Icons

This repository contains an alternative icon for LibreOffice.

## Files

PNG files are included for macOS, which accepts PNG or JPG images for app icons. An SVG file is also included, which Linux can use directly.

## Other sizes

A larger PNG is provided. However, if you need a size not provided here, open the SVG file in a vector graphics editor and export at the size you want.

## Changing the icon on macOS

1. Open the PNG file in Preview.
2. Select Edit > Copy (or press Cmd+C). This copies the image itself, not the file.
3. In Finder, locate the LibreOffice application.
4. Right-click it and select Get Info.
5. Click the small icon at the top left of the Info window so that it is highlighted.
6. Select Edit > Paste (or press Cmd+V).

The new icon will appear the next time you open or restart the app. If it looks blurred or pixelated, repeat the process using a larger PNG file or one with a higher resolution.
